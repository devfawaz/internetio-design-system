internet.io

One source for every value in the product

The Figma library defines its colours as variables; type, spacing and radius were not variables. The landing page and the app each carried their own values, and the two had drifted apart. These tokens close that gap: colours come from the library, the rest are derived from an audit of the code and recorded with the evidence.

1. Primitive

Raw values and scales, like --color-blue-600. Never used in component CSS.

2. Semantic

What components use, like --color-action-primary. Keeps var() references, so changing a primitive changes everything built on it.

3. Component

Specs like --button-height, including deliberate exceptions.

Click any swatch or token name to copy its CSS variable. Use the playground on the right to change one value and see everything on this page, and both products further down, follow.

Accessibility

Every text and control colour pair is measured against WCAG 2.2 AA on each build. A failing pair must be declared with a reason, or the test fails. Text needs 4.5:1 and control boundaries need 3:1.
